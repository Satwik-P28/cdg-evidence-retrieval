# R195: bounded evidence layouts with codec-cost dynamic programming

R194 completed on original QASPER. Whole-paper source blocks make most evidence unreachable under strict decoded-byte caps despite excellent storage. Improve representation rather than re-rank. Partition each paper into contiguous blocks of up to16 passages with cap2048 or4096 raw UTF8 bytes, except oversized indivisible singleton passages. Greedy maximum feasible span control, exact DP minimizing 64*(actual Zstd9 dictionary compressed bytes +64 byte block overhead proxy)+penalty*(number of passages-1)*raw block bytes. The second term is excess decode under a uniform single-passage request to each source, not real access traces; penalty0 and4 (1/16 relative weight). Exact optimality only over this proxy and allowed spans. Same source and index metadata schema as R194; source-only optimization, no human labels or query plan. Eight matched physical archive arms (individual, fixed4, greedy and two DP variants at each cap). Same top10 and byte budgets, actual source bytes and block inflation checks, evidence hits and paired comparisons. No first-of-kind claim or prompt token/device I/O result.

Local executed proof-of-concept: 300 random small partition cases compared with independent exhaustive enumeration, all exact. Actual Python stdlib first 100 lexically sorted top-level .py files, eight nonempty source lines per synthetic passage, 8845 passages, 2965017 raw bytes. zlib6 payload, not SQLite file bytes; no real user queries or evidence labels.
