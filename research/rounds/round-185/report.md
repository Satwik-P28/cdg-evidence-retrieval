# R185: finite signed suffix residuals and representation selection

Connect R155 core/bridge boundaries, R165 signed correction windows, R166–168 cancellation and multiplicities, R184 paired-context cancellation, and R99–106 adaptive representation selection. No RH theorem is used. Related work includes He/Suel versioned positional indexes (https://research.engineering.nyu.edu/~suel/papers/frag.pdf), signed historical index differences (https://research.engineering.nyu.edu/~suel/papers/version.pdf), compressed dynamic q-gram self-indexes (https://doi.org/10.1016/j.ic.2020.104518), and repetitive document retrieval (https://pmc.ncbi.nlm.nih.gov/articles/PMC5445192/). Prefix counts, suffix indexes and q-gram deltas are established; a first-of-kind claim is not justified.

For a window w, define S_L(w) as the multiset of all nonempty suffix prefixes w[i:i+L], truncated at the end. For any nonempty phrase q of length <=L, count(q,w) = sum_{s starts with q} S_L(w)[s], since each occurrence has one start. For paired old/new windows a,b, define sparse residual R=S_L(b)-S_L(a), cancel identical strings, retain signed integer multiplicity. Then delta(q)=sum_{s starts with q} R[s]. In lexical order with a sentinel larger than all tokens, these keys lie in [q,q+sentinel); two binary searches and a prefix sum subtraction suffice after decoding. For one substitution at most L old and L new truncated suffix instances change (less near boundaries); exact cancellation may reduce further. This is a bounded phrase count representation, not source reconstruction, arbitrary substring access or full positional retrieval.

Prototype uses fixed16 token IDs, front-coded sorted suffix residuals, signed int16 coefficients, zlib level6, resident decoded structures.
