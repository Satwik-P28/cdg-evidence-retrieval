# R165: one-hop signed phrase correction index

Status: implemented, unverified. Prior art is close: He/Zeng/Suel Improved Index Compression Techniques for Versioned Document Collections https://research.engineering.nyu.edu/~suel/papers/version.pdf (delta postings), He/Suel Optimizing Positional Index Structures https://research.engineering.nyu.edu/~suel/papers/frag.pdf (combined positional/nonpositional fragment indexes), Universal Indexes for Highly Repetitive Document Collections https://arxiv.org/abs/1604.08897 and LZ compressed indexing. Do not claim differential indexing or edit-boundary search is new. Specific hypothesis: reuse a one-hop index base and signed native edit-window phrase counts, ideally aligned with existing source compression anchor, with exact bounded phrase frequencies and no source recovery.

Lemma: for phrase length <=L, split edit script into changed groups separated by equal spans >=2(L-1). Surround each group with <=L-1 unchanged tokens each side, separately in old/new coordinates. Windows are disjoint within each sequence; every occurrence whose identity can differ is wholly inside one changed window. Occurrences outside windows, including crossing an outer window boundary, have a one-to-one equal-sequence correspondence (at least L-1 unchanged tokens between edit and boundary). Thus TF(new,p)=TF(old,p)+sum_windows(TF(newwindow,p)-TF(oldwindow,p)). This includes overlapping occurrences, pure insertions/deletions, repeated tokens, adjacent edits. Test exhaustive binary sequences length 0..4 and 150 randomized spaced edit pairs. Verify all native corpus queries against fresh snapshots. Multi-splice uses actual RapidFuzz Levenshtein opcodes (https://rapidfuzz.github.io/RapidFuzz/Usage/distance/Levenshtein.html), with exact token interning and equality checks; single-splice uses common prefix/suffix. Index base must be a previous full index content, not a delta, so query has one-hop algebraic dependency. Query expands base TF into active child content identities and adds signed native FTS patch counts; correct df and ranking computed from positive final TF. No source decode. Native FTS rows store each window independently (no fictitious cross-window phrases), encode sign and cid in rowid. Source recipe unchanged and physical source+index subset charged identically. Compare whole-content positional control, source-aligned single/multi splice, independently selected last4 local full index bases multi-splice. Admission proxy patch tokens+12 per pair+8 <=.75 child tokens; not optimal physical bytes. Both AP cohorts and CLARK, frozen queries plus up to24 edit-boundary probes; two warm passes, exact source bounds and native rank/df parity, separate preparation. Not arbitrary positional search, only phrase length <=8 and exact AND/OR. No full provenance or transactional claim. Need compare stronger positional delta index prior art before novelty claim.
