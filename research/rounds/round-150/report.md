# R150: exact-content quotient index and multiplicity-correct BM25

Status: implemented, unverified. Independent of R149 algorithm results.

Prior art includes He and Suel, Optimizing Positional Index Structures for Versioned Document Collections (SIGIR 2012), https://doi.org/10.1145/2348283.2348319; He/Zeng/Suel CIKM 2010 versioned index compression; Berberich et al. time-travel search and temporal coalescing; Universal Indexes for Highly Repetitive Document Collections, https://arxiv.org/abs/1604.08897. Do not claim content sharing or temporal index compression as new. Test a specific exact-content equivalence representation with active revision multiplicities and native FTS5 phrase counts. Different raw documents with equal tokens are not merged.

For cutoff c, let active revisions with content ID x form group G_x(c). All members have identical token length and phrase frequencies. Compute N=sum_x |G_x|, total=sum_x |G_x|*dl_x, df_p=sum_(x matching p)|G_x|. Score each qualifying content group with the original active BM25 formula, then recover the ordered top-k revisions. Only the k smallest generation IDs in each tied-score group can enter global top-k. This is an algebraic equivalence, not novel ranking; independent native oracle checks required. Compare native full revision contentless FTS5 with same active metadata, content-index plus expanded scoring, content-index plus group scoring. Charge physical SQLite pages including catalog and mapping; report preparation separately from query latency; no source archive or append semantics. Use same frozen AP cohorts and CLARK-News as low-redundancy independent corpus. 64 lexical probes plus 16 deterministic two-token phrases where available, all four cutoffs, exact ordered scores and df equivalence across arms. Tests include duplicate multiplicity, replacement, phrase conjunction and top-k ties. Do not generalize to arbitrary FTS syntax, vector search, or malicious index proofs. If successful, integrate with provenance v2 and compare fully matched complete archive.
