# R152 native-token equivalence and fair query controls

Status: implemented, unverified. Hypothesis: distinct source bytes may share the same ordered native FTS5 default unicode61 tokens; positional retrieval can share their index representation without merging source identities. The C extension exposes an unambiguous binary length-prefixed token sequence via the public tokenizer API (https://sqlite.org/fts5.html). Compare representative streams exactly after digest lookup, reject colocated synonyms, preserve positions by sequence order. Test against actual fts5vocab instance output, including Unicode, NUL, punctuation, repeats and empty source. No byte offsets or highlighting equivalence. Raw source and evidence are not merged. Existing repetitive indexing and fragment compression prior art: He/Suel https://doi.org/10.1145/2348283.2348319; Universal indexes https://arxiv.org/abs/1604.08897; repetitive document retrieval https://doi.org/10.1007/s10791-017-9297-7. No claim that normalization or sharing itself is new.

Three physical index-only arms: revision, exact raw and exact native-token sequence. Same active-statistics/mapping schema and mapping index, same materialized native phrase match SQL joined directly to active revision identities, same expanded per-revision BM25 scorer (no full ledger scan or snapshot preparation). Three shuffled query repetitions; compare exact native ranks, scores and df; charge complete SQLite bytes. Both frozen AP cohorts, independent CLARK and explicitly synthetic case/punctuation variant stress; no synthetic savings reported as real. No transactional integration in R152. R151's 27.67x latency comparison is confounded by full ledger loading; R152 tests a fairer query path at index level. A same-archive fast revision receipt control remains needed for full end-to-end timing attribution.

## Partial verified results

Three R152 jobs passed on a933b49e (https://github.com/Satwik-P28/cdg-evidence-retrieval/actions/runs/45881355795). Native stream vs FTS5 vocabulary and identity tests passed on all four jobs; full AP main experiment remains running. Small AP exact raw quotient 5,651 indexed rows / 11,153,408 B vs token quotient 5,637 / 11,116,544 B (0.33% smaller). CLARK no extra token-equivalent content; same size 2,777,088 B for both quotient arms vs revision 2,736,128 B. Explicitly synthetic formatting-variant cohort 11,753 revisions: raw quotient 7,390 rows / 14,233,600 B vs token 5,637 / 11,272,192 B (20.81% smaller). 8,640 native rank comparisons across 3 completed configurations, 3 arms and 3 repeats, all exact with zero observed score error. Small AP same-join query median 277.467 us revision, 209.258 us raw quotient, 212.206 us token. Marginal practical benefit on real corpora so far; synthetic stress demonstrates capability, not real-world benefit. Full archive fast revision control R153 pending.
