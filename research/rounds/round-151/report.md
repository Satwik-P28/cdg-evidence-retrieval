Status: implemented, unverified.

Use identical R147 frame catalog, origin ledger, native tokenizer, revision identities and rank receipt format. Original revision arm must reproduce R148 complete archive size. Both encoding arms must reproduce R149 source payload, distinct frames and logical work exactly. Quotient inserts one FTS row per exact source digest; compare representative recovered bytes on reuse, retain separate revision-to-content mapping and validity. Query uses materialized native phrase matches joined to active mappings; no full active map preparation. Correct N, total, df multiplicity and top-k tie handling. Full 256 rank probes, 64 batch replays, pinned historical readers, exact source reads. Charge all tables/indexes/sidecar. Timings descriptive. No cross-article recipes in this integration.
