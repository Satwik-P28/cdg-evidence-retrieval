# R184: signed correction certification and paired-context cancellation

Starting branch R168 weighted corrections 0a803c0d. This branch is independent of the R179–183 and paper drafts. Existing work: He/Suel, Optimizing Positional Index Structures for Versioned Document Collections, SIGIR 2012, https://doi.org/10.1145/2348283.2348319; Compact full-text indexing of versioned document collections (signed term frequency deltas), and Ding/Suel, Faster Top-k Document Retrieval Using Block-Max Indexes, SIGIR 2011 https://doi.org/10.1145/2009916.2010048. Neither signed differences nor score bounds alone are novel. No RH proof theorem is used.

## Theory
For a document's exact anchor count a and signed window counts x_i, the child count is a+sum c_i x_i. A phrase's count in any window is at most the minimum count of any of its distinct tokens. Given evaluated terms and bounds 0<=x_i<=U_i on remaining terms, subtract negative magnitudes from the lower bound and add positive magnitudes to the upper bound. Intersect with [0,max(0,dl-l+1)]. DF certification requires exact zero/nonzero for every active revision, including non-top-k documents; multiplicity expansion remains required. Once all DFs are exact, BM25 positive contributions are monotonic in tf for positive IDF, fixed dl/avg. Upper bounds may rule out a candidate, but equal score/tie candidates cannot be pruned. Floating guard used experimentally, not a fully proved IEEE-754 certificate.

Coupled pair lemma: A=PXS, B=PYS (common nonoverlapping prefix/suffix). Counts wholly within P or S cancel. For phrase length l, affected start range in w is [max(0,|P|-l+1), min(|w|-l+1,|w|-|S|)) in zero-based coordinates. If the middle is nonempty, each possible match must include a middle position i matching a query offset j, hence feasible start i-j; bound by cardinality of intersection of these starts with affected range. If middle empty, crossing the gap remains possible (must not apply token support test). Intersect this bound with unigram envelope. Then correction delta is in [-U_old,U_new]. Preserving pair metadata may be costly and conflicts with current independent quotient representation; no archive or speed claim yet.

## Actual local independent experiments
SQLite 3.46.1, Python stdlib, 320 synthetic edited documents per regime, common-token-skewed vocabulary, 160 tokens per document, sparse one substitution vs five separated substitutions. Eager and lazy both use same per-window unigram metadata. Eager/lazy eligible exact evaluations 47513/28358 (82 queries) and 230937/227137 (84 queries). All 166 top-10 and DF comparisons to native FTS5 passed; all source phrase-count differences checked. Wall seconds 0.674/0.662 and 1.348/1.331, single process, not meaningful speed superiority. No native compressed index or historical cutoff sweep in local probe.

Paired-bound experiment (coupled_probe.py): 139070 exhaustive/randomized identity+envelope checks, plus 240000 window/query pairs per regime. Substitution: independent zero 154781, combined zero 197900, independent width 447341, combined width 62265. Insertion: 173241/173241, width 320047/143017. Deletion: 185463/185463, width 247746/151438. Coupled-only bound is often looser than unigram-only (especially empty-middle insert/delete); use min, no universal strict improvement. Actual delta zero counts 239580/239756/238840: substantial room remains. These are synthetic bound/work counts, not retrieval speed or index size. Exact same coupled probe executed locally and committed.
