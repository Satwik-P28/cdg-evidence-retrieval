# R141: dated, labeled temporal retrieval on CLARK-News

Status: original-code job passed.

Li et al., Language Modeling with Editable External Knowledge (Findings NAACL 2025, https://aclanthology.org/2025.findings-naacl.168/). Pin belindal/ERASE b93f898780b3cf40fedd4e9a00c51af9a27688bc. Upstream questions.csv, timestamp_to_questions.json and external_sources.json; input hashes recorded. Unlike the NewsEdits synthetic global schedule, use actual released source-read timestamps, preserve source timestamp metadata, sort equal timestamps by URL, query after all available source rows. URL identifies a document; source text is upstream extracted text, not original HTML. Use known-answer intervals (not inferred event dates), unique nonempty non-yes/no labels only, deterministic hash sample up to 256 scheduled question/timestamp pairs, report exclusion counts. Questions are relation-derived, human-validated sources, not necessarily human-authored questions.

Fixed OR lexical term retrieval from question only (no gold answer or choices), native active-snapshot FTS5 oracle, transactional packed snapshot and bounded-anchor arms. Compare historical rank receipts and exact source reconstruction on final archive. Separately measure normalized contiguous gold-answer token presence at ranks 1/5/10 for historical vs final snapshot retrieval, and current URL resolution of historical hits. Report both directions of coverage changes. Gold token presence is an imperfect retrieval proxy; not semantic QA accuracy, generated answer quality or ERASE reproduction. No answer leakage via query choices. No raw source or question text exported in results. No claims until run passes.

## Verified results

R141 passed on b8f28140 (https://github.com/Satwik-P28/cdg-evidence-retrieval/actions/runs/45510196315). 1,161 released source texts for 1,157 URLs (only four multiversion URLs), six distinct cutoffs, 256 deterministic cases of 1,621 eligible; 3,700 ambiguous/nonextractive cases excluded. Historical vs latest-only answer-token coverage: top-1 93/256 vs 82/256, top-5 140 vs 144, top-10 146 vs 151. Two historical-only and seven latest-only top-10 successes. Ordered document lists change on 220/256; latest-URL resolution of original hits retains 146/256 top-10 coverage. Both snapshot and CDG replay all 256 historical receipts exactly, zero observed score error, 2,322 exact source readbacks and 5,094 evidence hit occurrences across arms. Complete archive 6,583,848 -> 6,564,548 bytes (0.293% reduction). Little revision redundancy explains limited compression benefit; no claim of semantic answer accuracy or consistent relevance superiority. Actual released read timestamps, not event timestamps; extracted text, relation-derived questions with human-validated sources, lexical gold presence proxy.
